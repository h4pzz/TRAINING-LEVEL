# План реалізації: Пряме сканування та завантаження документів екіпажу (Варіант А)

**Дата:** 3 листопада 2026 р.  
**Специфікація:** [`docs/superpowers/specs/2026-11-03-document-scanning-and-upload-design.md`](file:///d:/WIBECODING/TRAINING%20LEVEL/docs/superpowers/specs/2026-11-03-document-scanning-and-upload-design.md)  
**Статус:** Готовий до виконання  
**Ціль:** Оновити інтерфейс додавання документів у персональному кабінеті (`#view-personal-portal`), реалізувати підтримку прямого сканування через мобільну камеру (`capture="environment"`) та вибору готових файлів (Варіант А), автоматичне збереження в персональну папку на Google Диск (`Training level / [Flight Crew | Cabin crew] / [LastName_FirstName]`) та автооновлення дат підготовок для ролей `ADMIN` та `INSTRUCTOR`.

- [ ] **1.2 Редизайн модального вікна `#scan-modal-backdrop` (Варіант А):**
  - **Заголовок:** «Додати документ до папки співробітника» / «Add Document to Crew Member Folder».
  - **Бейдж контексту співробітника:** Додати контейнер `#scan-modal-crew-badge` (наприклад, `👤 Бондаренко Михайло [КПС]`), щоб користувач бачив, кому додається документ.
  - **Тип підготовки (`#scan-doc-type`):** Випадаючий список періодичних та додаткових підготовок.
  - **Дата проходження (`#scan-doc-date`):** Поле вибору дати тренування / сертифіката.
  - **Джерело документа (Секція Варіанта А):**
    - Прихований інпут камери: `<input type="file" id="scan-camera-input" accept="image/*,application/pdf" capture="environment" style="display:none;">`.
    - Прихований інпут файлів: `<input type="file" id="scan-file-input" accept="application/pdf,image/*" style="display:none;">`.
    - Сітка з 2 великих карток вибору джерела (`#scan-source-grid`):
      - Кнопка `#btn-source-camera`: 📷 «Сканувати камерою» (підпис: «Apple / Android скан»).
      - Кнопка `#btn-source-file`: 📁 «Вибрати файл» (підпис: «PDF / фото з пристрою»).
    - Блок попереднього перегляду готового документа (`#scan-file-preview`, прихований за замовчуванням):
      - Зелений бейдж із галочкою `✓`, назвою файлу (`#scan-preview-filename`), розміром (`#scan-preview-filesize`) та кнопкою скасування / видалення `#btn-clear-scan-file`.
  - **Кнопки дій у футері модального вікна:**
    - Кнопка «Скасувати» (`#btn-cancel-scan-modal`).
    - Кнопка відправки `#btn-submit-scan`: «☁️ Зберегти на Google Диск» (деактивована, доки файл не обрано та не вказано дату).

## Завдання 3: Логіка обробки, завантаження та Google Drive в `js/app.js`

- [ ] **3.1 Словники перекладів (`TRANSLATIONS`):**
  - Додати ключі для української та англійської мов:
    - `btn_add_document`: «Додати документ» / «Add Document»
    - `modal_add_doc_title`: «Додати документ до папки співробітника» / «Add Document to Crew Member Folder»
    - `scan_source_camera_title`: «Сканувати камерою» / «Scan with Camera»
    - `scan_source_camera_desc`: «Apple / Android скан» / «Camera / Mobile Scanner»
    - `scan_source_file_title`: «Вибрати файл» / «Choose File»
    - `scan_source_file_desc`: «PDF / фото з пристрою» / «PDF / Image from storage»
    - `btn_save_to_drive`: «Зберегти на Google Диск» / «Save to Google Drive»
    - `msg_doc_ready`: «Документ готовий до завантаження» / «Document ready for upload»
    - `msg_file_too_large`: «Розмір файлу перевищує 15 МБ» / «File size exceeds 15 MB»
- [ ] **3.2 Відкриття модального вікна та ініціалізація стану в `renderPersonalPortal()`:**
  - Налаштувати видимість кнопки `#btn-scan-document` для ролей `ADMIN` та `INSTRUCTOR`.
  - При кліку на кнопку:
    - Заповнити бейдж співробітника поточним іменем та посадою.
    - Очистити поля дати та приховані інпути.
    - Показати картки вибору джерела, приховати прев'ю готового файлу.
    - Встановити початковий стан кнопки збереження (disabled).
- [ ] **3.3 Слухачі подій вибору джерела (Камера vs Файл):**
  - Клік на `#btn-source-camera` $\rightarrow$ викликає `scanCameraInput.click()`.
  - Клік на `#btn-source-file` $\rightarrow$ викликає `scanFileInput.click()`.
  - Обробник вибору файлу (`change` для обох інпутів):
    - Перевірка розміру ($< 15\text{ МБ}$).
    - Збереження обраного файлу в локальній змінній сесії модалки.
    - Оновлення тексту в прев'ю (назва, розмір).
    - Перемикання інтерфейсу: сховати картки вибору, показати блок прев'ю.
    - Активація кнопки збереження при заповненій даті.
  - Клік на `#btn-clear-scan-file`:
    - Очищення файлів, повернення карток вибору, деактивація кнопки збереження.
  - Обробник зміни дати:
    - Якщо документ вже обрано $\rightarrow$ активувати кнопку збереження.
- [ ] **3.4 Відправка форми та синхронізація (`scanForm.onsubmit`):**
  - Формування стандартизованого імені файлу: `{TYPE}_{Full_Name_EN}_{YEAR}.{ext}`.
  - Анімація завантаження на кнопці збереження.
  - Завантаження у Google Диск у папку:
    `Training level / [Flight Crew | Cabin crew] / [LastName_FirstName]` через функцію `uploadCrewDocumentToDrive`.
  - Якщо Google Drive відключений або офлайн — збереження локально в Base64.
  - Розрахунок терміну дії для періодичних підготовок (`calculateExpiryDate`) або збереження дати проходження.
  - Оновлення `member[selectedType] = dateToSave`.
  - Додавання запису до `member.scans`.
  - Запис у системний журнал `STATE.changelog`.
  - Збереження у сховище `saveStateToStorage()`.
  - Закриття модального вікна, сповіщення `showToast`, та повторний рендеринг `renderPersonalPortal()`.
