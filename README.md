# 🚁 AeroCheck / UH Crew Training Level — Version 0.4

> **Система обліку кваліфікацій, рівня підготовки та тренувальних польотів авіаційного персоналу (Flight & Cabin Crew)**

---

## 🌟 Про проєкт

**AeroCheck (UH Crew Training Level)** — це сучасна веб-система (SPA) для контролю термінів дій допусків, проходження КПК, спеціальних тренувань та обліку польотної практики пілотів і бортпровідників.

Створена з урахуванням вимог авіаційних правил для двох профілів складів:
1. **Льотний склад (Flight Crew)**
2. **Кабінний склад (Cabin Crew)**

---

## 🚀 Функціонал версії 0.4 (v0.4)

### 📊 1. Моніторинг кваліфікацій та статусів
* **11 обов'язкових підготовок:** `OPC`, `OPC NVG`, `LPC`, `Тип ПС`, `EMER 1р`, `EMER 3р`, `DG`, `AV SEC`, `CRM`, `MED`, `LICENSE`.
* **Автоматичний розрахунок термінів дій:**
  * **Flight Crew:** Правило останнього дня місяця закінчення терміну (`end_of_month_rule`).
  * **Cabin Crew:** Точна річниця проходження (день-у-день), окрім `OPC` (останній день місяця).
* **Візуальні статус-бейджі:** 🟢 Дійсний / 🟡 Завершується (30 днів) / 🔴 Прострочено.

### 🏷️ 2. Оптимізовані таблиці з підказками (New in v0.3)
* **Компактні заголовки:** Таблиці оптимізовані за допомогою коротких авіаційних абревіатур (`OPC`, `LPC`, `EMER (1р)`, `DG`, `CRM` тощо) для комфортного перегляду на будь-яких екранах.
* **Інтерактивні підказки (Tooltips):** При наведенні курсору на будь-який заголовок виводиться повна офіційна назва підготовки українською або англійською мовою.

### 🔐 3. Рольова система доступу та безпека (New in v0.3)
* **Розподіл прав доступу:**
  * 👑 **ADMIN:** Повний доступ (Налаштування, редагування, додавання членів екіпажу, **ексклюзивне право на імпорт Excel-баз**).
  * 👨‍✈️ **INSTRUCTOR:** Доступ до тренувальних польотів, карток екіпажу, експорту.
  * 🏢 **OFFICE:** Доступ до перегляду статусів, формування та друку бланків.
  * 👤 **CREW:** Персональний портал пілота/бортпровідника для перегляду своїх документів та польотної книжки.
* **Захист імпорту:** Валідація прав на імпорт таблиць прямо у виконувальному шарі.

### ✈️ 4. Журнал тренувальних польотів (Training Flights Log)
* Внесення записів про виконувані тренувальні польоти (дата, тип ПС, вправа, тривалість, інструктор).
* Автоматичне фонове сповіщення (`dispatchFlightLogEmail`) та ведення історії змін.

### 📄 5. Форми та друковані бланки
* Генерація готових для друку бланків та заповнених відомостей про проходження КПК/тренувань.

### 📥 6. Розумний смарт-імпорт (Smart Merge Diff)
* Імпорт Excel-таблиць (.xlsx) через браузер без передачі на сторонні сервери.
* Алгоритм **Smart Merge**: автоматичне збереження та оновлення тільки тих дат, які є хронологічно новішими за існуючі в базі.

### 🌐 7. Повна двомовність (UA / EN)
* Миттєве переключення всієї термінології між українською та англійською мовами.
* Двомовний пошук по ПІБ (`Name_Shrt_UA` / `Full_Name_EN`).

## 🛠️ Технологічний стек

* **Frontend:** Vanilla HTML5, CSS3 (Custom CSS Variables, Responsive Grid), Pure JS (ES6+).

* **Архітектура:** 3-Layer Architecture (Directives SOPs ➔ Orchestration App State ➔ Execution Deterministic Engine).
