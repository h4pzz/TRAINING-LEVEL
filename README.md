# 🚁 AeroCheck / UH Crew Training Level — Version 0.6

> **Система обліку кваліфікацій, рівня підготовки та тренувальних польотів авіаційного персоналу (Flight & Cabin Crew)**

---

## 🌟 Про проєкт

**AeroCheck (UH Crew Training Level)** — це сучасна веб-система (SPA) для контролю термінів дій допусків, проходження КПК, спеціальних тренувань та обліку польотної практики пілотів і бортпровідників.

Створена з урахуванням вимог авіаційних правил для двох профілів складів:
1. **Льотний склад (Flight Crew)**
2. **Кабінний склад (Cabin Crew)**

---

## 🚀 Функціонал версії 0.6 (v0.6)

### 📈 1. Щомісячний архів польотів та інтерактивний тренд-графік (New in v0.6)
* **Вкладка архіву тренувальних польотів:** детальний реєстр виконаних польотів з фільтрацією за місяцями та інтерактивним пошуком.
* **SVG Line Trend Chart:** автоматична побудова тренду інтенсивності польотів за останні 6 місяців з підсвіткою поточного місяця та точними лічильниками.
* **Швидкий перегляд та редагування:** можливість редагувати та актуалізувати записи виконаних польотів безпосередньо з архіву для ролей Admin та Instructor.

### 📤 2. Експорт бази польотів та інтеграції (New in v0.6)
* **Вивантаження в XLSX та CSV:** експорт повної бази тренувальних польотів у табличні формати з коректним кодуванням UTF-8 BOM для кирилиці.
* **Щотижневі Email-звіти:** асинхронний диспетчер відправки звітів з налаштуванням адресатів, охоплення (вся база або останній політ) та форматів файлів (XLSX / CSV / Both).
* **Синхронізація з Google Drive:** підтримка резервного дублювання бази польотів у виділену хмарну папку.

### 📊 3. Моніторинг кваліфікацій та статусів
* **11 обов'язкових підготовок:** `OPC`, `OPC NVG`, `LPC`, `Тип ПС`, `EMER 1р`, `EMER 3р`, `DG`, `AV SEC`, `CRM`, `MED`, `LICENSE`.
* **Додаткові спеціальні підготовки:** `GI 275 (T/PRCT)`, `Bird Strike`, `MSB`, `PALL`, `HESLO`, `FFO` (Fire Fighting Operations), `HHO`.
* **Автоматичний розрахунок термінів дій:**
  * **Flight Crew:** Правило останнього дня місяця закінчення терміну (`end_of_month_rule`).
  * **Cabin Crew:** Точна річниця проходження (день-у-день), окрім `OPC` (останній день місяця).
* **Візуальні статус-бейджі:** 🟢 Дійсний / 🟡 Завершується (30 днів) / 🔴 Прострочено.

### 🏷️ 4. Оптимізовані таблиці з підказками та гнучким інтерфейсом
* **Компактні заголовки:** Таблиці оптимізовані за допомогою коротких авіаційних абревіатур (`OPC`, `LPC`, `EMER (1р)`, `DG`, `CRM` тощо).
* **Інтерактивні підказки (Tooltips):** При наведенні курсору виводиться повна офіційна назва підготовки.
* **Адаптивна геометрія:** Розрахунок мінімальної ширини колонок по контенту, симетричні відступи та підтримка мобільного бічного меню (Drawer Navigation).

### 🔐 5. Рольова система доступу та безпека
* **Розподіл прав доступу:**
  * 👑 **ADMIN:** Повний доступ (Налаштування, редагування, додавання членів екіпажу, **ексклюзивне право на імпорт Excel-баз**, завантаження та видалення скан-копій).
  * 👨‍✈️ **INSTRUCTOR:** Доступ до тренувальних польотів, карток екіпажу, експорту.
  * 🏢 **OFFICE:** Доступ до перегляду статусів, формування та друку бланків.
  * 👤 **CREW:** Персональний портал пілота/бортпровідника для перегляду документів, скан-копій та польотної книжки.

### 📥 6. Розумний смарт-імпорт (Smart Merge Diff)
* Імпорт Excel-таблиць (.xlsx) через браузер за алгоритмом **Smart Merge**: оновлення тільки тих дат, які є хронологічно новішими за існуючі в базі.

### 🌐 7. Повна двомовність (UA / EN)
* Миттєве переключення всієї термінології та пошуку між українською та англійською мовами.

## 🛠️ Технологічний стек

* **Frontend:** Vanilla HTML5, CSS3 (Custom CSS Variables, Responsive Grid), Pure JS (ES6+).
* **Екосистема:** SheetJS (обробка XLSX у браузері), Lucide Icons.
* **Архітектура:** 3-Layer Architecture (Directives SOPs ➔ Orchestration App State ➔ Execution Deterministic Engine).
